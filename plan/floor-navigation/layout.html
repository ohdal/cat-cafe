· 좌측 상단 FloorIndicator는 Hud.tsx의 햄버거 버튼(우측 상단)과 좌우 대칭 위치, currentFloor(예: 1F)를 표시.
· 클릭 시 뜨는 층 선택 모달은 CafeMenuPanel과 같은 화이트+그레이+하늘색 토큰, 잠금 행은 동일한 rgba(0,0,0,0.7) 오버레이 재사용.
· shaft 모델: 5F~1F를 위→아래 물리적 순서로 쌓은 #shaft 하나만 translateY로 움직인다(뷰포트 H=240px, 최고층 maxF일 때 offset(F) = (maxF - F) * H, translateY = -offset(F)).
· 1F→5F 예시: 시작 translateY(1F) = -960px → 끝 translateY(5F) = 0px. 값이 증가(shaft가 아래로 흘러감)하면서 4F·3F·2F 슬라이스가 차례로 화면을 스쳐 지나간다 — 위층으로 갈수록 건물이 상대적으로 내려가는 엘리베이터 시점(요구 5·6). 아래층 이동은 반대로 값이 줄어들며 shaft가 위로 올라간다 — 부호 분기 없이 같은 offset 공식 하나로 처리.
· 5F 슬라이스에는 Counter/MenuBoard가 없다 — 1F 전용(결정 사항). 층마다 벽/바닥 색이 다른 건 스윕 진행을 눈으로 구분하기 위한 데모용 표시일 뿐, 지금 범위에선 실제로 모든 층이 같은 가구/스킨 데이터를 공유한다(층별 꾸미기는 후속 작업).
